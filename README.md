# 딩동 펫

정해진 시간마다 화면 아래에서 쏙 올라와 **지금 몇 시인지 읽어 주고 응원해 주는** Windows 데스크톱 펫이에요.

![말풍선을 띄운 고양이와 해파리](docs/preview.png)

- 정각을 기준으로 10분·30분·1시간처럼 정해 둔 간격마다 알려 줘요.
- 캐릭터는 **고양이**와 **해파리** 중에 고를 수 있어요.
- 소리를 낼 수 없는 자리에서는 **무음 모드**로 화면 테두리 번쩍임, 반짝이, 폴짝 뛰기만으로 알려요. 처음에는 무음 모드로 시작해요.
- 마우스로 끌어서 옮길 수 있고, 모니터가 여러 대여도 돼요.

## 바로 시작하기

1. **Python 설치** — [python.org](https://www.python.org/downloads/)에서 받아 설치해요. 설치 첫 화면에서
   **"Add python.exe to PATH"** 를 꼭 체크해 주세요. (Python 3.11에서 만들고 확인했어요)
2. **이 저장소 받기** — 위쪽 초록색 **Code → Download ZIP** 으로 받아 압축을 풀어요.
3. **`run.bat` 더블클릭** — 화면 오른쪽 아래에 펫 머리가 살짝 보이면 성공이에요.
   펫을 한 번 누르면 바로 올라와서 말해요.
4. 소리로 듣고 싶으면 펫을 **우클릭 → "무음 모드" 체크 해제**.

컴퓨터를 켤 때마다 자동으로 실행하려면 `Win + R` → `shell:startup` 을 열고, 그 폴더에 `run.bat` 바로 가기를 넣어 두세요.

## 목소리

### 키 없이 바로: [HD] 아케르나르

기본 목소리 **아케르나르**는 미리 만들어 둔 음성 파일(`voices/`)이 함께 들어 있어서 **API 키 없이 바로** 읽어 줘요.

- 하루 전체의 **10분 단위 시각 멘트**(말투 7가지)
- **기본 응원 문구 30개**

알림 간격을 **10분의 배수**(10, 20, 30, 60분 …)로 쓰면 모든 알림을 이 목소리로 읽어 줘요.

### 그 밖의 경우

아래 경우에는 미리 만든 음성이 없어서, 새로 만들려면 Google API 키가 필요해요.

- 5분·15분처럼 10분 단위가 아닌 간격이나 시각
- 설정 창에서 직접 쓴 응원 문구
- 아케르나르가 아닌 다른 Google 목소리

키가 없으면 무료 음성 **edge-tts(선희)** 로 대신 읽어요(아래 선택 설치, 인터넷 연결 필요).
그것도 없으면 소리 없이 말풍선만 띄워요.

### Google API 키 넣기 (선택)

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고 **Cloud Text-to-Speech API** 를 사용 설정해요. (결제 계정 연결이 필요해요)
2. **API 및 서비스 → 사용자 인증 정보 → API 키 만들기**. 키는 Text-to-Speech API만 쓰도록 제한해 두는 걸 권해요.
3. 펫 **우클릭 → 설정 → Google API 키** 에 붙여 넣고 저장해요.

- 키는 앱 폴더의 `tts_api_key.txt` 에 저장되고 git에는 올라가지 않아요. 환경 변수 `GOOGLE_TTS_KEY` 로 줘도 돼요.
- 한 번 만든 음성은 `audio_cache/` 에 저장해 두고 다시 쓰기 때문에 같은 문장으로는 API를 다시 부르지 않아요.
- 비용이 걱정되면 설정의 **새 시각 멘트 생성 시간대**와 **월 글자 수 한도**(기본 5만 자)로 사용량을 묶어 둘 수 있어요.
  요금은 Google Cloud Text-to-Speech 가격 정책을 따라요.
- **음성 미리 생성** 버튼으로 필요한 음성을 한 번에 만들어 둘 수도 있어요.

## 선택 설치

```
pip install edge-tts pillow
```

- `edge-tts` — 키 없이 쓰는 무료 대체 음성
- `pillow` — 효과 GIF를 더 깔끔하게 재생

## 사용법

| 동작 | 하는 일 |
| --- | --- |
| 펫 누르기 | 지금 바로 올라와서 말하기 |
| 펫 끌기 | 옮기기. 놓으면 그 모니터 아래쪽에 붙어요 |
| 우클릭 | 지금 나오기 · 무음 모드 · 설정 · 위치(구석 정렬, 다음 모니터로) · 종료 |

**설정 창**에서 바꿀 수 있는 것: 캐릭터, 알림 간격, 목소리(미리 듣기), 딩동 소리, 무음 모드와 시각 효과,
펫 뒤에서 재생할 효과 GIF, 말풍선 유지 시간, 응원 문구.

**특별 알림** — 매주 정해진 요일·시각에 다른 설정을 모두 제치고 요란하게 알려 줘요. 처음에는 꺼져 있어요.
요일·시각·문구는 [`dingdong/config.py`](dingdong/config.py) 위쪽의 `SPECIAL_*` 값으로 바꿔요.

## 파일 구성

```
run.bat            더블클릭으로 실행 (pythonw pet.py)
pet.py             실행 파일
dingdong/          앱 본체
  app.py             펫: 자리 잡기, 알림 일정, 나와서 말하기, 애니메이션
  settings.py        설정 창
  characters.py      고양이·해파리 그리기 (새 캐릭터는 여기 클래스를 추가해 등록)
  bubble.py          말풍선
  effects.py         화면 테두리 글로우, 반짝이, 효과 GIF
  voice.py           딩동 소리 재생, 음성 합성(Google / edge-tts)과 캐시
  phrases.py         시각 멘트·응원 문구
  config.py          기본 설정, 목소리 목록, 특별 알림
  screen.py          모니터 정보 (Win32)
voices/            함께 배포하는 아케르나르 음성
*.mp3              딩동 소리
```

실행하면 앱 폴더에 생기는 개인 파일(git에 올라가지 않음): `config.json`(설정), `usage.json`(이번 달 API 사용량),
`tts_api_key.txt`(API 키), `audio_cache/`(직접 만든 음성).
